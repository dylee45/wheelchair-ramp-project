# YOLO 기반 휠체어 통행 가능 경사로 판별 시스템

## 1. 프로젝트 소개

본 프로젝트는 YOLO Object Detection과 Segmentation 기술을 활용하여 사진 속 경사로 및 주변 환경을 분석하고, 휠체어 통행 가능 여부를 지도에 표시하는 시스템을 개발하는 것을 목표로 한다.

사용자가 건물 입구나 통행로의 사진을 업로드하면 경사로를 탐지하고, 보행 영역과 장애물의 관계를 분석하여 통행 가능 여부를 판단하는 기능을 구현할 예정이다.

## 2. 주요 기능

- **Object Detection:** 사진 속 경사로 및 장애물 탐지
- **Segmentation:** 경사로와 보행 가능 영역 분할
- **통행 조건 분석:** 장애물과 보행 영역의 관계 및 통행 조건 분석
- **사용자 인터페이스:** 사진 업로드 및 분석 결과 확인
- **지도 시각화:** 위치별 통행 가능 여부 표시

※ 실제 경사각과 폭의 정확한 측정에는 별도 측정 정보가 필요할 수 있으며, 초기 구현에서는 측정값 입력 또는 판별 보류 기능을 고려한다.

## 통행 조건 분석 기능

### 목적

Object Detection과 Segmentation 결과 및 별도로 확인한 경사로 폭과 경사각 정보를 활용하여 통행 조건을 분석한다.

### 주요 기능

- 경사로 탐지 여부 확인
- 경사로 영역 분할 여부 확인
- 경사로 폭 및 경사각 조건 비교
- 통행 경로 장애물 여부 확인
- 조건 충족 / 통행 불가 / 판단 보류 결과 반환
- 판단 사유 출력

### 실행 방법

`python src/analysis.py`

### 현재 구현 범위

현재는 분석 조건문의 정상 동작을 확인하는 초기 테스트 단계이다. 경사로 폭과 경사각은 직접 입력하며, 임시 기준값은 실제 접근성 기준으로 검증되지 않았다.

추후 YOLO 모델의 실제 추론 결과와 연동하고, 검증된 접근성 기준을 적용할 예정이다.

## YOLO 통합 분석

### 개발 목적

Object Detection, Segmentation 및 통행 조건 분석 기능을 하나의 프로그램으로 통합한다.

### 처리 과정

1. 사용자가 입력한 경사로 이미지 불러오기
2. YOLO Object Detection으로 경사로 위치 탐지
3. YOLO Segmentation으로 경사로 및 계단 영역 분할
4. 탐지 결과를 통행 조건 분석 모듈에 전달
5. 분석 결과와 판단 사유 출력

### 실행 방법

`python main.py`

### 결과 저장 위치

`results/integration/`

### 현재 구현 범위

- 경사로 존재 여부 자동 탐지
- 경사로 및 계단 영역 분할
- 모델 예측 결과를 분석 모듈에 전달
- 통행 조건 판단 결과 출력

경사로 폭과 경사각은 현재 자동 측정되지 않으므로, 측정 정보가 없는 경우 판단 보류로 처리한다.

## Streamlit 사용자 인터페이스

### 개발 목적

사용자가 웹 화면에서 경사로 사진을 업로드하고 YOLO 분석 결과를 확인할 수 있도록 구현한다.

### 주요 기능

- JPG, JPEG, PNG 이미지 업로드
- YOLO Object Detection 결과 시각화
- YOLO Segmentation 결과 시각화
- 경사로 폭 및 경사각 측정값 선택 입력
- 통행 조건 분석 결과와 판단 사유 출력

### 실행 방법

`python -m streamlit run src/app.py`

실행 후 브라우저에서 `http://localhost:8501`에 접속한다.

### 현재 제한 사항

- 경사로 폭과 경사각은 자동 계산되지 않음
- 장애물의 통행 방해 여부는 아직 판단하지 않음
- 판정 기준은 초기 테스트용 임시값이며 실제 접근성 기준 검증이 필요함
- 지도 표시 기능은 추후 구현 예정

## 지도 기반 경사로 분석 결과 표시

### 개발 목적

경사로 사진의 YOLO 분석 결과를 지도에 표시하여 사용자가 특정 위치의 통행 조건을 확인할 수 있도록 한다.

### 사용 기술

- Folium: 지도 생성 및 마커 표시
- Streamlit-Folium: Streamlit 웹 화면에 지도 출력

### 주요 기능

- 경사로 위치의 위도 및 경도 입력
- YOLO 분석 결과에 따른 지도 마커 생성
- 조건 충족: 초록색 마커
- 통행 불가: 빨간색 마커
- 판단 보류: 주황색 마커
- 마커 클릭 시 분석 결과 확인

### 현재 제한 사항

- 위치는 사용자가 직접 입력
- 경사로 위치 자동 추출 기능 미구현
- 분석 결과는 초기 테스트 조건에 따른 것으로 실제 통행 안전성을 보장하지 않음
- 여러 경사로 위치 저장 및 조회 기능은 추후 구현 예정

### 장애물 여부 입력 및 통행 조건 분석

- 사용자에게 경사로 폭, 경사각, 장애물 여부 입력받기
- YOLO Detection 및 Segmentation 결과와 사용자 입력 정보 통합
- 테스트 조건에 따라 조건 충족, 통행 불가, 판단 보류로 분류
- 최종 결과를 지도와 CSV 분석 기록에 반영
- 장애물 자동 탐지는 추후 모델 개선 단계에서 구현 예정

※ 현재 판정 기준은 시범용이며 실제 통행 안전성을 보장하지 않음.

### 최종 통행 조건 판정

YOLO Object Detection과 Segmentation의 경사로 인식 결과, 사용자가 입력한 경사로 폭·경사각·장애물 여부를 종합하여 세 가지 상태로 분류한다.

- **조건 충족:** 모든 시범 테스트 조건을 충족한 경우
- **통행 불가:** 입력된 폭·경사각 또는 장애물 조건을 충족하지 못한 경우
- **판단 보류:** 경사로 인식에 실패하거나 필요한 정보가 부족한 경우

현재 폭 120cm, 경사각 5도는 프로그램 테스트용 임시 기준이다. 실제 통행 가능 여부를 보증하지 않으며, 향후 데이터셋 보강 및 판정 기준 검증이 필요하다.

### 장애물 자동 탐지

- 사전 학습된 YOLO11n 모델 활용
- 사람, 자전거, 의자 등 장애물 후보 객체 탐지
- 장애물 후보의 위치(Bounding Box)와 신뢰도 출력
- 장애물 탐지 결과 이미지 저장
- 향후 Segmentation으로 얻은 경사로 영역과 장애물 위치를 비교할 예정

현재 장애물 탐지는 객체 존재 여부만 확인하며, 실제 통행 방해 여부는 판단하지 않는다.

### 경사로와 장애물 영역 분석

- YOLO Segmentation으로 경사로 마스크 추출
- 사전 학습된 YOLO Detection으로 장애물 후보 탐지
- 장애물 Bounding Box와 경사로 마스크의 겹침 비율 계산
- 겹침 감지, 겹침 미감지, 판단 불가로 분류
- 경사로 마스크와 장애물 박스를 결과 이미지에 시각화

현재 겹침 비율 기준은 테스트용이며, 실제 휠체어 통행 차단 여부를 보장하지 않는다.

### YOLO 통합 분석

Streamlit 웹 애플리케이션에서 세 가지 YOLO 분석을 통합 실행한다.

1. Object Detection을 이용한 경사로 위치 탐지
2. Segmentation을 이용한 경사로 및 계단 영역 구분
3. 사전 학습된 YOLO 모델을 이용한 장애물 후보 탐지
4. 경사로 마스크와 장애물 Bounding Box의 겹침 비율 계산
5. 분석 결과 시각화 및 기존 통행 조건 판정
6. 지도에 결과 저장 및 분석 기록 관리

현재 장애물 겹침 결과는 참고 정보이며, 최종 통행 조건 판정에는 아직 자동 반영하지 않는다.
