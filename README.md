
# 휠체어 사용자를 위한 경사로 탐지 및 통행 조건 분석

## 1. 프로젝트 소개

YOLO Object Detection과 Segmentation을 활용하여
사진 속 경사로와 장애물 후보를 분석하고,
결과를 지도에 표시하는 시범 프로그램입니다.

사용자가 경사로 사진과 위치 정보를 입력하면
모델이 경사로와 장애물 후보를 탐지하고,
입력된 폭과 경사각 조건을 함께 분석합니다.

본 프로그램은 학습 및 연구용 프로토타입이며
실제 휠체어 통행 안전성을 보장하지 않습니다.

## 2. 주요 기능

- 경사로 Object Detection
- 경사로 및 계단 Segmentation
- 장애물 후보 자동 Detection
- 경사로 영역과 장애물 Bounding Box 겹침 분석
- 경사로 폭 및 경사각 조건 분석
- 분석 결과 및 사유 출력
- 지도 마커 표시
- CSV 분석 기록 저장 및 삭제
- 동일 위치의 최신 기록 표시

## 3. 사용 기술

- Python
- Ultralytics YOLO11
- Streamlit
- Folium
- OpenCV
- NumPy
- Roboflow
- GitHub

## 4. 분석 과정

1. 사용자가 경사로 사진을 업로드합니다.
2. Object Detection으로 경사로를 탐지합니다.
3. Segmentation으로 경사로 영역을 분할합니다.
4. 별도 YOLO 모델로 장애물 후보를 탐지합니다.
5. 경사로 마스크와 장애물 박스의 겹침을 분석합니다.
6. 입력한 폭과 경사각을 시범 기준과 비교합니다.
7. 판정 결과와 사유를 지도 및 CSV에 저장합니다.

## 5. 판정 기준

현재 시범 프로그램의 입력 조건은 다음과 같습니다.

- 경사로 폭: 120cm 이상
- 경사각: 5도 이하
- 장애물: 자동 탐지 및 겹침 분석

폭과 경사각 기준은 기능 테스트를 위한 임시값이며,
법적 적합성이나 실제 통행 안전성을 검증한 기준이 아닙니다.

현재 자동 장애물 분석에서는 물체가 탐지되지 않아도
장애물이 없다고 확정하지 않습니다.

따라서 폭 또는 경사각 조건 위반이 확인되면
"통행 불가"로 표시하고,
그 외 자동 분석 결과는 원칙적으로
"판단 보류"로 처리합니다.

## 6. 설치 방법

Python 가상환경을 생성합니다.

Windows:

    python -m venv .venv
    .venv\Scripts\activate

필요한 라이브러리를 설치합니다.

    python -m pip install -r requirements.txt

## 7. 모델 파일 준비

학습된 모델 가중치는 다음 경로에 배치합니다.

경사로 Detection:

    runs/detect/ramp_test/weights/best.pt

경사로 Segmentation:

    runs/segment/ramp_seg_test/weights/best.pt

장애물 Detection:

    yolo11n.pt

장애물 탐지 모델은 최초 실행 시 다운로드될 수 있습니다.

GitHub 저장소에는 학습 데이터와 가중치가
포함되지 않을 수 있으므로 별도 전달이 필요합니다.

## 8. 프로그램 실행

프로젝트 루트에서 다음 명령어를 실행합니다.

    python -m streamlit run src/app.py

실행 후 웹 브라우저에서 사진을 업로드하고
분석을 진행합니다.

## 9. 테스트

단위 테스트:

    python -m unittest discover -s tests -v

수동 테스트 항목:

- 사진 업로드
- 세 YOLO 모델 실행
- 경사로 및 장애물 결과 출력
- 겹침 분석
- 조건 판정
- 지도 갱신
- CSV 저장 및 삭제

## 10. 현재 한계

- 경사로 Segmentation 정확도가 낮을 수 있습니다.
- 일부 장애물은 탐지하지 못할 수 있습니다.
- 장애물 박스와 경사로 마스크가 겹친다고 해서
  실제 통행 차단이 확정되는 것은 아닙니다.
- 단일 사진만으로 실제 경사로 폭과 경사각을
  신뢰성 있게 측정하지 못합니다.
- 위치 좌표는 사용자가 입력하며
  사진의 실제 촬영 위치를 자동 검증하지 않습니다.
